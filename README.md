# Java Bank Account Simulator

A simple console-based Java application that simulates basic bank account operations.

## Features

- Create a bank account
- Store account holder details
- Generate an account number
- Deposit money
- Withdraw money
- Check current balance
- View account details
- View transaction history

## Account Details Stored

- Account holder name
- Date of birth
- Gender
- Address
- Account number
- Current balance

## Concepts Used

- Java Classes and Objects
- Constructors
- Encapsulation
- ArrayList
- Random
- Methods
- Switch Statement
- Do-While Loop
- Scanner
